# goodoldjava

이 프로젝트는 `JDK 25`, `Maven`, `Spring`, `Spring Boot`, `Spring Web`을 사용합니다.

## 기술 스택 설명

### JDK 25

JDK(Java Development Kit)는 자바 애플리케이션을 개발하고 실행하는 데 필요한 도구 모음입니다.  
이 프로젝트에서는 `pom.xml`의 `java.version`이 `25`로 설정되어 있으므로, 빌드와 실행을 위해 JDK 25 환경이 필요합니다.

- 자바 소스 코드를 컴파일할 수 있습니다.
- 애플리케이션 실행에 필요한 JVM을 제공합니다.
- 최신 자바 버전을 기준으로 프로젝트를 관리할 수 있습니다.

### Maven

Maven은 자바 프로젝트의 빌드와 의존성 관리를 담당하는 도구입니다.  
이 프로젝트에서는 루트의 `pom.xml`이 Maven 설정 파일이며, 필요한 라이브러리와 빌드 방식을 정의합니다.

- 의존성 다운로드 및 버전 관리를 처리합니다.
- 테스트, 패키징, 실행 같은 표준 빌드 작업을 통일된 방식으로 수행합니다.
- `mvnw`, `mvnw.cmd`를 통해 로컬에 Maven이 따로 설치되지 않아도 프로젝트를 실행할 수 있습니다.

### Spring

Spring은 자바 애플리케이션 개발을 위한 핵심 프레임워크입니다.  
의존성 주입(DI), 객체 생성 관리(IoC), 계층 분리 같은 구조를 쉽게 적용할 수 있게 해 줍니다.

이 프로젝트에서는 `@RestController` 같은 애노테이션을 통해 스프링이 클래스를 관리하고, HTTP 요청을 처리할 수 있도록 구성합니다.

### Spring Boot

Spring Boot는 Spring 애플리케이션을 더 빠르고 간단하게 실행할 수 있도록 도와주는 확장 프레임워크입니다.  
복잡한 초기 설정을 줄이고, 실행 가능한 애플리케이션을 손쉽게 만들 수 있도록 자동 설정(Auto Configuration)과 내장 서버 구성을 제공합니다.

이 프로젝트에서는 `GoodoldjavaApplication` 클래스의 `@SpringBootApplication`이 진입점 역할을 하며, `SpringApplication.run(...)`으로 애플리케이션을 시작합니다.

- 스프링 애플리케이션의 기본 설정을 자동으로 구성합니다.
- 내장 웹 서버 기반으로 빠르게 실행할 수 있습니다.
- 설정을 단순화해 작은 예제부터 실서비스까지 일관된 구조를 유지할 수 있습니다.

### Spring Web

Spring Web은 웹 요청과 응답을 처리하기 위한 스프링 모듈입니다.  
이 프로젝트에서는 `spring-boot-starter-webmvc` 의존성을 사용하고 있으며, REST API나 웹 엔드포인트를 만들 수 있습니다.

이 프로젝트에서 Spring Web은 사용자의 HTTP 요청을 받아 컨트롤러 메서드로 연결하고, 그 결과를 응답으로 돌려주는 역할을 합니다.

## 실행 방법

### 애플리케이션 실행

```bash
./mvnw spring-boot:run
```

실행 후 브라우저에서 아래 주소로 접속할 수 있습니다.

```text
http://localhost:8080/
```

### 테스트 실행

```bash
./mvnw test
```
